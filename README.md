# proxyo
My unified management script for shadowsocks and xray servers.
For personal use.

This repository contains my wrapper script, it invokes the one-click scripts from the following upstream projects, it does **not** include or redistribute their source code:

- [mack-a/v2ray-agent](https://github.com/mack-a/v2ray-agent)
- [teddysun/shadowsocks_install](https://github.com/teddysun/shadowsocks_install)

Please refer to each upstream repository for its license.
Many thanks to the authors.
